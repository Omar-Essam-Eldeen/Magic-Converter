# Converter App v1.3 — "Brand & Artwork" (design/identity stage)

Built on top of v1.2. **No conversion-engine or behaviour changes**: `src/lib/converters/*`, `src/lib/detect.ts` and all v1.1/v1.2 logic are untouched; the layout-shift fix (fixed-footprint header toggles, `color-scheme`, `scrollbar-gutter`) and all a11y support (focus-visible rings, aria-live announcer, progressbar roles, reduced-motion rules) are intact. `npm run build` passes clean (tsc strict + vite); no new dependencies. All artwork is original hand-drawn SVG — no icon-library glyphs, no stock.

## 1. The logo mark

**Concept (one line):** two overlapping pages in dark ink on a tangerine-gradient squircle — the front page's folded corner sweeps out into a bold rightward arrowhead, answered beneath by a shorter return arc: conversion, both ways.

Design rationale:
- **Tile:** rounded squircle (58×58 on a 64 grid, r16) filled with the brand gradient #E85D04 → #F2760A → #FFB25E (userSpaceOnUse, so every gradient-filled detail samples the exact colour behind it), plus a soft top sheen clipped to the tile.
- **Pages:** the back page is a plain ink (#14100C) rounded rect; the front page carries the folded corner and wears a 2.4-unit gradient "halo" stroke so it lifts cleanly off the back page at any size. Its fold flap is filled with the tile gradient — the corner looks peeled back to reveal the brand colour.
- **Arrowhead:** a single bold ink triangle whose base is buried inside the front page, so page and arrow read as one merged silhouette — the fold literally becomes the conversion arrow. Beneath, a 4-unit stroked return arc with its own arrowhead completes the two-way story.
- **Small sizes / monochrome:** strokes and masses are chunky (nothing thinner than the 2.4 halo); rendered and eyeballed at 256/64/24px during design — pages, arrow and arc stay legible at 24px, and with the gradient removed the ink shapes still read as "pages + arrow + return" against the tile silhouette.

Deliverables: master vector at `public/logo.svg`; inline twin at `src/components/Logo.tsx` (`Logo` with `size`/`decorative` props + an exported `LogoGlyph` for nesting inside other SVGs — keep them in sync). The header's generic double-arrow glyph is replaced by `<Logo size={42}/>` inside the existing `.brand-mark` slot (same 42×42 footprint, gradient chip background removed in favour of a drop-shadow on the mark itself, so the lockup height — and the header — is pixel-identical to v1.2).

## 4. Category artwork — `src/components/CategoryIcon.tsx`

Eight original duotone glyphs (24×24, stroke-based), sharing the logo's language: a muted-slate page/frame base (`currentColor` via `.cat-icon`, theme-aware) + exactly one tangerine motif (`var(--accent)` via `.ci-*` classes in styles.css):
- **image** — frame + mountain ridge + sun dot · **video** — frame + play triangle · **audio** — frame + waveform bars · **pdf** — folded page + tangerine bookmark ribbon · **data** — page + table grid with a highlighted (tangerine) header row · **text** — page + ruled lines + an abstract pilcrow flourish (paths only, no letters) · **archive** — lidded box + zipper teeth + pull tab · **unknown** — page + question mark drawn as a path with an ink dot.
Used in every queue row beside the file name (~22px, `aria-hidden` — the existing category text label stays). Row layout change is minimal and RTL-safe: `.q-file` becomes a centred flex row with a logical `gap`, name/meta wrapped in `.q-file-text` (min-width 0, so ellipsis behaviour is unchanged).
